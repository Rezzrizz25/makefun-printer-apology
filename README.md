A make.fun entry for the **The Printer Apology** bounty: write the funniest one-line apology from a printer, 120 characters max.

## The entry

> I'm sorry I ate your report. In my defence, you fed me staples, cheap paper, and a 200-page PDF at 4:59 on a Friday.

(116 characters. The printer apologises, then puts the office on trial: staples, cheap paper, a 200-page PDF — and the punch lands on the 4:59 Friday print job, the true crime.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–120 characters, plus a read-back verification that the file on disk is byte-identical to the entry.
